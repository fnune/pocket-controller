Pocket Controller screens

Every screen from docs/design/screen.md drawn as the TrimUI Brick shows it (1024 by 768, 4:3). Buttons are named by their printed Nintendo label.

Theme and font used: NextUI's default theme colours from workspace/all/common/config.h (color1 ffffff, color2 9b2257, color3 1e2329, color6 ffffff, color7 000000) and its default font, Rounded Mplus 1c Bold (font id 1, "Next"), taken from the reduced copy in workspace/all/show2 and embedded here. Colour roles are inferred from how api.c and nextui.c use them (selected pill white with dark text, button hint circles pink, settings bar track dark), so they are approximate. The black background is an assumption. The real helper reads the user's own theme from minuisettings.txt.

Waiting for a USB connection

A state screen changes only once the new state is settled; while the link is in flux the previous screen stays and a three-dot indicator shows. Three states. The graphic is drawn only from filled rectangles, filled circles and text, so the real helper can reproduce it. The Brick cannot tell "no cable" from "a cable with no power", so both show the first state.
