# Fonts

`rounded-mplus-1c-bold-subset.ttf` is a subset of Rounded M+ 1c Bold, used only to render the SVG sources to PNG. Rounded M+ is derived from the M+ fonts and keeps their licence:

> These fonts are free software. Unlimited permission is granted to use, copy, and distribute them, with or without modification, either commercially or noncommercially. THESE FONTS ARE PROVIDED "AS IS" WITHOUT WARRANTY.

The screen helper draws text at runtime with the handheld's own font, not this one.
